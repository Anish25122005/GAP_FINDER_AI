# GapFinder AI

**Defensible Knowledge Gap Analysis & Grounded Educational Assessment**

> **Core Problem:** Students often spend equal amounts of time revising every topic, even though their knowledge varies significantly across subjects and concepts. Conventional chatbots answer questions you ask—they do not diagnose what you *don't* understand.
>
> **Core Product Principle:** The primary output of GapFinder AI is a **defensible diagnosis of the student's knowledge gaps**, not merely answers generated by a chatbot. Every major AI-generated result is traceable to real evidence in the student's uploaded learning material.

## 4. Getting Started Locally

### Prerequisites
- Node.js >= 20 (Node 24 recommended)
- npm >= 10

### 1. Clone & Install Dependencies
```bash
git clone <repository-url>
cd hackon
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

For offline development and testing, `.env.local` runs out of the box with `AI_PROVIDER="mock"`.
To connect live AI and Supabase services, configure:
```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL="https://your-project.supabase.co"
NEXT_PUBLIC_SUPABASE_ANON_KEY="your-anon-key"
SUPABASE_SERVICE_ROLE_KEY="your-service-role-key"

# Live AI Providers
AI_PROVIDER="openai" # or "gemini"
OPENAI_API_KEY="sk-proj-your-openai-api-key"
OPENAI_MODEL="gpt-4o-mini"
OPENAI_EMBEDDING_MODEL="text-embedding-3-small"
```

### 3. Run Automated Tests
```bash
npm test
```
All 7 test suites (24 tests) run and pass in ~500ms.

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Instant Demo Experience
Click **"Launch Instant Demo (CS 401)"** on the landing page or login screen to automatically seed:

- Notes: Pre-chunked and embedded lecture notes covering architectures, Byzantine faults, CAP/PACELC, Paxos/Raft consensus, consistent hashing, and quorums.

## 5. Database Schema & Supabase Migrations

The database migration is located in `supabase/migrations/20260101000000_initial_schema.sql` and `src/lib/db/schema.sql`.

### To apply to Supabase:
```bash
# Using Supabase CLI
supabase db push

# Or run the SQL script directly in the Supabase Dashboard SQL Editor
# File: supabase/migrations/20260101000000_initial_schema.sql
```

Key database entities:
- `profiles`: User accounts linked with Supabase Auth
- `subjects`: Academic courses
- `topics`: Hierarchical syllabus units & topics
- `documents`: Uploaded PDF and TXT learning materials
- `document_chunks`: Chunks with 1536-dimensional `pgvector` embeddings
- `topic_chunk_mappings`: Semantic relevance scores linking topics to chunks
- `generated_questions`: Grounded MCQs and short-answer rubrics
- `quizzes` & `quiz_attempts`: Persistent student quiz sessions
- `student_answers` & `answer_evaluations`: Deterministic grades, partial credit, and identified/missing concepts
- `topic_mastery_snapshots`: Deterministic gap analysis scores, confidence, and status
- `revision_plans` & `revision_plan_items`: Time-budgeted priority calendar tasks
- `chat_sessions` & `chat_messages`: Grounded topic assistant chat with citations
- `match_document_chunks()`: Postgres RPC function for vector similarity search with user isolation

## 6. Deployment to Vercel

1. Push your repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import this repository.
4. Set the Environment Variables in Vercel Project Settings matching `.env.example`:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `OPENAI_API_KEY` (or `GEMINI_API_KEY`)
   - `AI_PROVIDER`
5. Click **Deploy**. Next.js will compile the static routes and serverless route handlers automatically.
